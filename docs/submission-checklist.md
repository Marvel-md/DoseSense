# Submission checklist

This checklist reflects the Round 1 requirements previously supplied for this hackathon. It is not a fresh confirmation of the organiser's current rules or deadline. Check the final organiser instructions if they have changed.

## PDF

- [ ] Use the official PPT template and preserve its required structure/layout.
- [ ] Replace every team, member, problem-statement and link placeholder with confirmed details.
- [ ] Export to PDF, not PPT/PPTX; keep the PDF under 4 MB.
- [ ] Use the filename `TeamID_TeamName_ProblemStatementID.pdf` with actual identifiers.
- [ ] Remove institute names, logos and identifying backgrounds as required.
- [ ] Read every page of the exported PDF: no clipping, missing content or unreadable text.
- [ ] Check every claim against the generated results in `docs/presentation.md`.
- [ ] State that results are synthetic and commercial figures are proposed assumptions.

## Video

- [ ] Final export is at most 3:00 with a prototype demo (the supplied rule was 2:00 without a prototype).
- [ ] Every registered member appears on camera.
- [ ] English narration; resolution at least 640×480.
- [ ] Show the running application with verified cases and readable screen text.
- [ ] Watch/listen to the exported recording from start to finish.
- [ ] Test the actual submitted video link in an incognito window with no account access.

## Repository and demonstration

- [ ] Submit the public repository/commit containing the corrections, not an older local copy.
- [ ] Reproduce from a clean setup on the presentation machine.
- [ ] Python tests and `python scripts/check_demo.py` pass.
- [ ] `python scripts/make_report.py --check` passes.
- [ ] Rehearse the exact walkthrough and confirm the displayed cases match narration.
- [ ] Keep any claimed live URL accessible; a running localhost demo is not a public hosted link.
- [ ] Keep the app limited to synthetic data and identify the role switch as a demonstration.

## What this repository cannot confirm automatically

The final official-template PDF, the actual video, member appearances, team identifiers, final submission links, organiser deadline and successful portal submission need to be checked against those exact artifacts. Adding this checklist does not mean those gates have passed.
